# Content options and search

## Content options

`chapters.get`, `verses.get`, `passages.get` and `sections.get` accept the same rendering options.
The SDK takes them in camelCase and sends them as kebab-case query parameters.

| SDK option | Query parameter | Values | API default |
| --- | --- | --- | --- |
| `contentType` | `content-type` | `'html'`, `'text'`, `'json'` | `html` |
| `includeNotes` | `include-notes` | boolean | `false` |
| `includeTitles` | `include-titles` | boolean | `true` |
| `includeChapterNumbers` | `include-chapter-numbers` | boolean | `false` |
| `includeVerseNumbers` | `include-verse-numbers` | boolean | `true` |
| `includeVerseSpans` | `include-verse-spans` | boolean | `false` |
| `parallels` | `parallels` | array of `bibleId`s (comma-separated on the wire) | none |

The type of `content` depends on `contentType`. It is a string for `html` and `text`, and an array
of nodes for `json`.

`html` is the default, so a request with no options returns HTML with titles and verse numbers.
Ask for `text` explicitly when you want plain text.

### Recommended combinations

Clean reading view, plain text, for an app, a notification or a verse-of-the-day:

```ts
import type { PassageGetParams } from '@americanbible/api-bible-sdk';

export const readingView: PassageGetParams = {
  contentType: 'text',
  includeNotes: false,
  includeTitles: true,
  includeVerseNumbers: true,
};
```

Study view, with structure, footnotes and per-verse markup you can style or link:

```ts
import type { PassageGetParams } from '@americanbible/api-bible-sdk';

export const studyView: PassageGetParams = {
  contentType: 'html',
  includeNotes: true,
  includeTitles: true,
  includeVerseNumbers: true,
  includeVerseSpans: true,
};
```

Use `json` when you need to walk the structure yourself, for example to render your own
components or to attach data to individual verses.

`html` content is generated by API.Bible, but treat it like any third-party HTML: sanitize it
before you insert it into a page.

## Search

```ts
import { createBibleClient, isKeywordSearchResult, isReferenceSearchResult } from '@americanbible/api-bible-sdk';

const client = createBibleClient({ apiKey: process.env.BIBLE_API_KEY! });

const { data } = await client.search.search('de4e12af7f28f599-01', { query: 'faith hope love' });

if (isReferenceSearchResult(data)) {
  for (const passage of data.passages) console.log(passage.reference, passage.content);
} else if (isKeywordSearchResult(data)) {
  console.log(`${data.total} matching verses`);
  for (const verse of data.verses) console.log(verse.reference, verse.text);
}
```

| SDK param | Query parameter | Meaning |
| --- | --- | --- |
| `query` | `query` | **Required.** A missing query returns 400. |
| `limit` | `limit` | Results per page. Default 10, capped at 200. |
| `offset` | `offset` | Results to skip. Default 0. |
| `sort` | `sort` | `'relevance'` (default), `'canonical'` or `'reverse-canonical'`. |
| `range` | `range` | Limit the search to passages: comma-separated IDs, e.g. `'GEN'` or `'MAT.1-MAT.5'`. |
| `fuzziness` | `fuzziness` | `'AUTO'` (default), `'0'`, `'1'` or `'2'`: how many character edits still count as a match. |

How a query matches:

- **Every keyword must match.** `faith hope love` finds only verses that contain all three words.
  To find verses with any of them, run one search per word.
- `*` matches any run of characters and `?` matches one: `bless*`, `l?ve`.

### Two result shapes

The API chooses the shape from the query itself. No parameter selects it.

- **Keyword query** (`"love"`, `"faith hope"`): `query`, `limit`, `offset`, `total`, `verseCount`
  and `verses`, where each verse has `reference` and `text`. A search with no matches still has
  this shape, with `verses: []`.
- **A query that reads as a reference** (`"John 3:16-19"`, `"John 3"`): only `passages`, with each
  passage's `content`.

Every field on `SearchResult` is optional, so narrow with `isKeywordSearchResult` and
`isReferenceSearchResult` instead of checking fields. That also makes search a convenient way to
turn a free-text reference typed by a user into a passage.

### Pagination

```ts
import { createBibleClient, isKeywordSearchResult } from '@americanbible/api-bible-sdk';

const client = createBibleClient({ apiKey: process.env.BIBLE_API_KEY! });
const PAGE_SIZE = 50;

export async function searchAll(bibleId: string, query: string) {
  const verses = [];
  for (let offset = 0; ; offset += PAGE_SIZE) {
    const { data } = await client.search.search(bibleId, { query, limit: PAGE_SIZE, offset });
    if (!isKeywordSearchResult(data)) break;
    verses.push(...data.verses);
    if (data.verses.length === 0 || offset + PAGE_SIZE >= data.total) break;
  }
  return verses;
}
```

Each page is one API call against your quota. Fetch further pages only when the user asks for them.

Search responses also carry `meta.fumsToken`. Report it when you show the results (see
`licensing-and-fums.md`).
